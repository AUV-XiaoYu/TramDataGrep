## 一、这套工具是干什么的

简单说：**让公司内网任何一台电脑，打开浏览器就能把 Oracle 数据库里的运营数据表下载成 Excel 或 CSV 文件。**

解决的问题：
- 以前可能需要找 DBA 导数据 → 现在自己打开网页就能下载
- 一张表几百万行太大 → 系统自动拆成多个小文件，还支持按日期范围筛选
- 只有授权的人能用 → 管理员可以创建账号、控制权限

## 二、准备一台 Windows 电脑

### 2.1 选哪台机器

满足以下条件即可：

| 要求 | 说明 |
|------|------|
| 能连 Oracle 数据库 | ping 一下 Oracle 服务器能通 |
| Windows 7+ 或 Windows Server | 64 位系统 |
| 内存 ≥ 4GB | 8GB 以上更好，内存越大能下载的表越大 |
| 公司内网 | 同一网段的电脑能访问这台机器 |

### 2.2 安装 Python（只需装一次）

1. 打开浏览器，访问 **https://www.python.org/downloads/**
2. 点击黄色大按钮 "Download Python 3.x.x" 下载安装包
3. **双击运行安装包**
4. ⚠️ **重要**：安装界面第一页，**勾选底部的 "Add Python to PATH"**（把 Python 加到系统路径）
5. 点击 "Install Now" 等待安装完成

> **验证是否装好**：按键盘 `Win + R`，输入 `cmd` 回车，在黑色窗口输入 `python --version` 回车。如果显示 `Python 3.x.x` 就说明装好了。

### 2.3 获取项目文件

把整个 `tram` 文件夹复制到这台电脑上，随便放哪个盘都可以。**建议直接放 D 盘根目录**，路径就是 `D:\tram`。

> 之后文档里所有路径都用 `D:\tram` 举例。如果你放到了别的位置，把路径换成你的实际位置就行。

## 三、部署步骤（只需做一次）

### 3.1 确认 Oracle 连接信息

在开始之前，确认以下信息（找 DBA 或知道数据库信息的人要）：

| 信息 | 示例 | 说明 |
|------|------|------|
| Oracle 服务器 IP | `192.168.1.100` | 数据库服务器的内网地址 |
| 端口号 | `1521` | 一般是 1521 |
| 服务名 | `ORCL` | Oracle 的服务名/SID |
| 用户名 | `tram` | 连接数据库用的账号 |
| 密码 | `tram123` | 连接数据库用的密码 |

> ⚠️ Oracle 账号只需要 **SELECT（查询）权限**就够了，不需要修改或删除权限，这样即使误操作也不会影响数据库。

### 3.2 修改启动配置

用**记事本**打开 `D:\tram\start.bat`，找到文件最顶部这几行：

```batch
set ORACLE_USER=tram
set ORACLE_PASSWORD=tram123
set ORACLE_DSN=localhost:1521/ORCL
set WEB_PORT=8080
```

把它们改成你的实际值：

```batch
set ORACLE_USER=实际的Oracle用户名
set ORACLE_PASSWORD=实际的Oracle密码
set ORACLE_DSN=数据库IP:端口/服务名        （例如 192.168.1.100:1521/ORCL）
set WEB_PORT=8080                          （Web 端口，一般不用改）
```

改完保存、关掉记事本。

> **端口说明**：`8080` 是同事浏览器访问时要输入的端口号。如果这台电脑上 8080 端口已被其他程序占用，换一个比如 `8090`。

### 3.3 双击启动（首次部署）

1. 打开 `D:\tram` 文件夹
2. **双击 `start.bat`**
3. 会弹出一个黑色命令行窗口，自动做以下事情：
   - 检查 Python 是否正常
   - 创建一个隔离的 Python 环境（`venv` 文件夹，首次约 1-2 分钟）
   - 安装必要的软件包（首次约 1 分钟）
   - 创建管理员账号
4. 看到类似下面的输出，说明启动成功：

```
======================================================
  电车票务数据平台
  Tram Data Export Platform
======================================================
  访问地址:    http://localhost:8080
  默认管理员:  admin
  默认密码:    Admin@tram2026
------------------------------------------------------
  服务器内存:  8192 MB (可用 4096 MB)
  安全下载上限: ~1228 MB / 3,221,225 行
======================================================
```

### 3.4 验证部署成功

1. 在这台电脑上打开浏览器，访问 **http://localhost:8080**
2. 应该看到登录页面
3. 用以下信息登录：
   - **用户名**：`admin`
   - **密码**：`Admin@tram2026`
4. 登录后应该看到数据库中的表列表

> ✅ 看到表列表 = 部署成功！

### 3.5 让同事也能访问

在服务器电脑上查询本机 IP 地址：

1. 按 `Win + R`，输入 `cmd` 回车
2. 输入 `ipconfig` 回车
3. 找到 "IPv4 地址"，类似 `192.168.1.50`

同事在内网其他电脑上打开浏览器，访问 **http://192.168.1.50:8080** 即可。

> 如果同事访问不了，检查 Windows 防火墙是否放行了 8080 端口（参考第七章"常见问题处理"）。

## 四、启动与停止服务

### 4.1 启动

**双击 `D:\tram\start.bat`** 即可。

> 那个黑色命令行窗口不要关，关了服务就停了。

### 4.2 停止

在黑色命令行窗口按 **`Ctrl + C`**，窗口会关闭，服务停止。

### 4.3 重启

先按 `Ctrl + C` 停掉，再双击 `start.bat` 启动。

> 如果改了配置（比如 Oracle 密码），需要重启才能生效。

### 4.4 日常运行建议

- 第一次部署成功后，这台电脑就作为"数据下载服务器"一直开着
- 黑色窗口可以最小化，不要关
- 建议参考第八章设置成开机自启，这样电脑重启后不用手动再开

## 五、日常使用指南

> 这部分写给每天需要下载运营数据的同事。登录后就能看到所有可下载的表。

### 5.1 登录

浏览器打开 `http://服务器IP:8080`，输入自己的用户名和密码。

### 5.2 浏览和搜索表

登录后看到的是**表列表页面**：

- 表按 Schema（可以理解为"文件夹"）分组显示
- 每个表后面有**行数**，颜色代表数据量大小：
  - 灰色 = 小表（几万行以下）
  - 黄色 = 中等表
  - 红色 = 大表（需要分片下载）
- 顶部的搜索框可以直接搜索表名

点击任意表名进入**表详情页**。

### 5.3 按日期筛选数据（最常用的功能）

打开一张表后，如果表里有日期列，页面顶部会出现一个**"按日期筛选"卡片**：

```
┌─────────────────────────────────────────────────────────┐
│ 📅 按日期筛选                                            │
│                                                         │
│ 日期列 [FLOW_DATE ▼]  开始日期 [____]  结束日期 [____]  │
│ [🔍 查询]  [❌ 清除]                                    │
└─────────────────────────────────────────────────────────┘
```

**操作步骤**：
1. 在"日期列"下拉框中选择要筛选的日期字段（比如 `FLOW_DATE`）
2. 日期框自动变为可用状态——点击输入框弹出日历，选择开始日期和结束日期
3. 点击「查询」按钮
4. 页面刷新后会显示：
   - **筛选后行数**（比如从 210 万变成了 5 万）
   - **预估文件大小**
   - **下载建议**（安全下载 / 需要分片等）

> 💡 **技巧**：如果想导出某一天的清分数据，把开始日期和结束日期选为同一天即可。

### 5.4 下载数据

#### 情况一：小表（页面没有分片提示）

直接点击 **Excel** 或 **CSV** 按钮，浏览器就会开始下载。

- **Excel**（.xlsx）：推荐，可以用 Excel/WPS 打开
- **CSV**（.csv）：纯文本格式，文件更小，适合导入其他系统

#### 情况二：大表（页面提示需要分片）

页面会出现一个**"分片下载"卡片**：

```
┌──────────────────────────────────────────────────────────┐
│ 🧩 分片下载                          共 24 片 | 24 片    │
│                                                          │
│ [📦 下载全部分片 (Excel ZIP)] [📦 CSV ZIP]               │
│ ⏳ 正在打包 24 个分片，请稍候...                           │
│                                                          │
│ ▶ 或逐个下载单片（24 片）                                  │
└──────────────────────────────────────────────────────────┘
```

**推荐方式**：点 **「下载全部分片 (Excel ZIP)」**，系统会自动把所有分片打成一个 ZIP 压缩包。下载后解压，里面有 24 个 Excel 文件，每个约 50 万行。

**备选方式**：点击"或逐个下载单片"展开所有分片按钮，点哪个下载哪个。适合只需要其中一两片的情况。

#### 情况三：表太大（"仅支持分片下载"）

有些表超过 500 万行，不能直接一次下载。**只能通过分片方式下载**（见情况二）。

### 5.5 理解下载分级

| 页面提示 | 含义 | 你该怎么做 |
|----------|------|-----------|
| 绿色提示 "可以安全下载" | 表不大，直接下 | 点 Excel 或 CSV 按钮 |
| 蓝色提示 "可能需要几分钟" | 表比较大 | 等一下就好，也可以分片 |
| 黄色警告 "建议分片" | 表很大 | 建议点"下载全部分片 (ZIP)" |
| 红色警告 "仅支持分片" | 表超大 | 只能用分片方式下载 |

## 六、用户管理（管理员操作）

> 只有 admin 账号能看到导航栏的「用户管理」入口。

### 6.1 创建新用户

1. 点击导航栏 **「用户管理」**
2. 点击 **「新建用户」** 按钮
3. 填写：
   - **用户名**：登录用的账号（英文）
   - **密码**：至少 6 位
   - **显示名称**：随意，显示在右上角
   - **管理员权限**：勾选则拥有管理权限（能管理用户、看诊断页）
4. 点击「保存」

### 6.2 重置密码

用户忘记密码时：
1. 在用户管理页面找到该用户
2. 点击 **「重置密码」**
3. 系统会生成一个随机新密码，把新密码告诉用户
4. 提醒用户登录后立即修改密码

### 6.3 禁用/启用用户

- 点击 **「禁用」**：该用户无法登录，但数据还在
- 点击 **「启用」**：恢复登录权限
- ⚠️ 管理员不能禁用自己

### 6.4 删除用户

点击 **「删除」**——实际上是标记为不可用，不会真的删除数据。管理员不能删除自己。

## 七、常见问题处理

### 7.1 同事访问不了这个系统

**现象**：服务器本机可以打开 `http://localhost:8080`，但其他电脑打不开 `http://服务器IP:8080`

**解决方法**——开放 Windows 防火墙端口：

1. 按 `Win + R`，输入 `wf.msc` 回车（打开高级防火墙）
2. 左侧点击「入站规则」
3. 右侧点击「新建规则...」
4. 选择「端口」→ 下一步
5. 选择「TCP」，输入 `8080` → 下一步
6. 选择「允许连接」→ 下一步
7. 全选（域/专用/公用）→ 下一步
8. 名称填 `Tram Data Export` → 完成

> 如果公司有网络防火墙，可能还需要网络管理员在交换机/防火墙上放行。

### 7.2 启动时报错"无法解析 DSN"

**原因**：Oracle 连接信息配置错了。

**检查步骤**：
1. 确认 Oracle 服务器 IP 能 ping 通：打开 cmd，输入 `ping 192.168.1.100`（换成实际 IP）
2. 打开 `start.bat`，检查 `ORACLE_DSN` 格式是否正确：`IP:端口/服务名`，例如 `192.168.1.100:1521/ORCL`
3. 确认防火墙没有拦截 Oracle 的 1521 端口

### 7.3 忘记管理员密码

1. 关闭服务（在黑色窗口按 `Ctrl + C`）
2. 打开 `D:\tram\instance` 文件夹
3. **删除 `users.db` 文件**
4. 重新双击 `start.bat` 启动
5. 系统会自动重建管理员账号：`admin` / `Admin@tram2026`
6. ⚠️ 之前创建的其他用户也会被清掉，需要重新创建

### 7.4 下载到一半失败了

**可能原因和解决方法**：

| 原因 | 解决方法 |
|------|---------|
| 表太大，内存不够 | 用分片下载，每片小一点 |
| 网络断了 | 刷新页面重试 |
| Oracle 连接超时 | 可能是 Oracle 服务器忙，稍等几分钟再试 |
| 服务器内存不足 | 关闭其他占用内存的程序，或者给电脑加内存 |

### 7.5 下载的 Excel 打开后中文乱码

- **Excel 文件 (.xlsx)**：不会有这个问题，直接打开就行
- **CSV 文件 (.csv)**：用 Excel 打开时，选择「数据」→「从文本/CSV 导入」，选 UTF-8 编码导入

### 7.6 如何只显示部分表

如果 Oracle 数据库里表很多，只想显示跟运营相关的表，可以加过滤规则。

打开 `start.bat`，在文件开头加上这两行：

```batch
set TABLE_FILTER_MODE=whitelist
set TABLE_FILTER_PATTERNS=["DAILY%","CLEARING%","PASSENGER%","TXN%"]
```

这样只显示表名以 DAILY、CLEARING、PASSENGER、TXN 开头的表。

> `%` 是通配符，`DAILY%` 表示"以 DAILY 开头的所有表"。

## 八、让服务开机自启（可选）

> 如果不想每次重启电脑后手动双击 `start.bat`，可以把服务注册成 Windows 服务。

### 8.1 下载 NSSM

1. 打开 https://nssm.cc/download
2. 下载 `nssm-2.24.zip`（或最新版本）
3. 解压，找到 `nssm.exe`（64 位系统用 win64 文件夹里的）

### 8.2 注册服务

1. 把 `nssm.exe` 放到 `D:\tram\` 目录下
2. 用**管理员身份**打开 cmd（按 Win，输入 cmd，右键"以管理员身份运行"）
3. 输入以下命令：

```batch
D:\tram\nssm.exe install TramDataExport
```

4. 会弹出一个窗口，填写：

| 字段 | 值 |
|------|-----|
| **Application Path** | `D:\tram\venv\Scripts\python.exe` |
| **Startup Directory** | `D:\tram` |
| **Arguments** | `-c "from waitress import serve; from app import create_app; serve(create_app(), host='0.0.0.0', port=8080)"` |

5. 点击 "Install service"

### 8.3 管理服务

```batch
D:\tram\nssm.exe start TramDataExport     # 启动
D:\tram\nssm.exe stop TramDataExport      # 停止
D:\tram\nssm.exe restart TramDataExport   # 重启
D:\tram\nssm.exe status TramDataExport    # 查看状态
```

注册成功后，每次电脑重启，服务会自动启动，不需要手动操作。

> 要卸载服务：`D:\tram\nssm.exe remove TramDataExport`

## 九、附录：高级配置

> 以下是高级配置项。大多数情况下不需要改，默认值已经够用。

### 9.1 所有配置项

配置通过 `start.bat` 里的 `set` 语句设置：

```batch
REM ==== Oracle 连接 ====
set ORACLE_USER=tram
set ORACLE_PASSWORD=tram123
set ORACLE_DSN=localhost:1521/ORCL

REM ==== Web 服务 ====
set WEB_PORT=8080

REM ==== 演示模式（设为 1 就不需要 Oracle，用模拟数据）====
set DEMO_MODE=0

REM ==== 表过滤 ====
set TABLE_FILTER_MODE=all              REM all / whitelist / blacklist
set TABLE_FILTER_PATTERNS=[]           REM JSON 数组，如 ["DAILY%","TXN%"]

REM ==== 下载安全阈值 ====
set DOWNLOAD_WARN_ROWS=100000          REM 超过此行数显示"大表"提醒
set DOWNLOAD_CONFIRM_ROWS=500000       REM 超过此行数需要确认
set MAX_DOWNLOAD_ROWS=5000000          REM 硬上限，超过只能分片下载
set DOWNLOAD_SPLIT_CHUNK_ROWS=500000   REM 分片下载每片多少行
set DOWNLOAD_SPLIT_SIZE_MB=100         REM 预估文件超过此 MB 数就建议分片
```

### 9.2 用系统环境变量代替（推荐生产环境）

在 `start.bat` 里写密码不太安全。更好的做法是用 Windows 系统环境变量：

1. 按 `Win + R`，输入 `sysdm.cpl` 回车
2. 「高级」→「环境变量」
3. 点击「新建」，逐个添加：

| 变量名 | 值 |
|--------|-----|
| `ORACLE_USER` | 数据库用户名 |
| `ORACLE_PASSWORD` | 数据库密码 |
| `ORACLE_DSN` | 数据库地址 |

4. 设置完后，`start.bat` 里的 `set` 行可以删掉（系统环境变量优先级更高）

### 9.3 检查服务器硬件能力

管理员登录后，点击导航栏的 **「系统诊断」**，可以看到：

- 服务器总内存和可用内存
- 自动计算的安全下载上限
- Oracle 连接是否正常 + 延迟
- 数据库表的统计概览

如果"可用内存"长期很低，说明这台机器内存不太够，考虑加内存或换一台配置更好的机器。
